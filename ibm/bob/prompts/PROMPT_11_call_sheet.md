# PROMPT 11 — Call Sheet Artifact

## Task

Build `src/pri/artifacts/call_sheet.py` using `reportlab`.

```python
generate_call_sheet(state, day_date) -> bytes          # PDF
regenerate_all(state) -> list[Artifact]                # called by TransitionService step 6
```

## The PDF must look like a real call sheet

Judges include people who will recognise a fake one.

- **header**: production title, day N of M, date, weather, sunrise/sunset
- crew call time, first shot time, estimated wrap
- **location block**: name, address, parking, nearest hospital
- **scenes table**: scene no | INT/EXT | D/N | description | pages | cast ids | est. minutes
- **cast table**: id | character | pickup | call | on set
- **equipment list**
- **footer**: `Generated by PRI — state version {v} — {digest[:12]}`

## Storage

`artifacts/call_sheets/{production}/v{version}/{date}.pdf`, and register a row in
the `artifacts` table.

## Visual diff hook

```python
generate_call_sheet_delta(old_state, new_state, day)
```

marks changed rows with a `CHANGED` flag so the demo can show before/after.

## Acceptance Criteria

- A generated PDF opens
- Version + digest in the footer **match the committed state**
