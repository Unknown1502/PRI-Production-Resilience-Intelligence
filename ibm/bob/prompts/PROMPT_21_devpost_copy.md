# PROMPT 21 — Devpost Copy

## Task

Draft the Devpost submission text (`docs/hackathon/devpost.md`), covering:

- inspiration
- what it does
- how we built it
- challenges
- accomplishments
- what we learned
- what's next
- built-with

## Requirements from the rules

A text description summarising **features and functionality, technologies used,
data sources, and findings/learnings**.

## Editorial direction

- Lead with the problem in production terms and a **real cost of a lost shooting day**
- Name the **deterministic/LLM split as the design thesis**
- Name IBM Bob's actual role in development **specifically** — which components it
  built, not "we used Bob"
- State the Confluent role in one sentence
- **Do not oversell**: no invented benchmark numbers, no claims about self-aware AI

## Length

**Under 900 words.** Judges read many of these.
